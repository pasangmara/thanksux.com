## Spec
- Trim 3.5 × 2 in, bleed 0.125 in, safe zone 0.125 in inside trim
- Type: name 12 pt (Montserrat Bold), everything else 9 pt minimum (Inter)
- Colours: Navy `#0B1F3A`, Blue `#1E6FD9`, Sky `#38B6FF`
- QR codes: vector, re-encoded from the supplied WeChat and WhatsApp codes and scan-tested

## Illustrator
1. Open the PRINT PDF. Each page opens as its own artboard at the exact inch size.
2. File → Document Color Mode → CMYK.
3. Type → Create Outlines before sending to press.
