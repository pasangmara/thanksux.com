TIMES INTERNATIONAL - VISITING CARD
MD JAKIR HOSSEN, CEO
=====================================================

Size : 3.5 x 2 inch (trim)  +  0.125 inch bleed every side
       -> artboard 3.75 x 2.25 inch (270 x 162 pt)
Safe : keep text 0.125 inch inside the trim line
Type : name 12 pt, everything else 9 pt minimum
Fonts: Montserrat (SemiBold / Bold / ExtraBold) + Inter (Regular / Medium / SemiBold)
Color: Navy #0B1F3A   Blue #1E6FD9   Sky #38B6FF
QR   : WeChat + WhatsApp, vector, scan-tested

FOLDERS
-------
01_Print_Ready
  ...-PRINT.pdf            2 pages (front, back), vector, fonts embedded
  ...-PRINT-outlined.pdf   same, all text converted to outlines
                           -> SEND THIS ONE TO THE PRESS (no fonts needed)
  ...-PRINT-cropmarks.pdf  same with crop marks, if the press wants marks

02_Illustrator_Editable
  ...-Front.ai / ...-Back.ai    open in Adobe Illustrator, 1 artboard each,
                                exact inch size, editable text
  ...-Front.svg / ...-Back.svg  same artwork as SVG (live text)

03_Fonts
  Install all .otf files BEFORE opening the .ai / .svg files,
  otherwise Illustrator will substitute fonts. (Free, SIL Open Font License)

04_Mockup
  ...-MOCKUP.pdf / .png    presentation mockup + spec sheet

ILLUSTRATOR E KAJ KORAR NIYOM
-----------------------------
1. Age 03_Fonts er shob font install korun.
2. 02_Illustrator_Editable theke Front.ai / Back.ai khulun - lekha edit kora jabe.
3. File > Document Color Mode > CMYK kore nin.
4. Edit shesh hole: Type > Create Outlines, tarpor File > Save As > PDF
   (Adobe PDF Preset: Press Quality, Marks and Bleeds e "Use Document Bleed").
5. Edit na korle shorashori 01_Print_Ready/...-PRINT-outlined.pdf press e pathan.
