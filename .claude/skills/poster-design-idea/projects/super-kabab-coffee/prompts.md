# ChatGPT Prompts: SKC Campaign Elements

How to use:
1. Open a new ChatGPT chat and paste the **Master Rules** from the main
   ASSETS prompt list first.
2. Add this line once: `For dark subjects use pure white (#FFFFFF) background.`
3. Send each prompt below.
4. Upload the images here with their ID (e.g. "SKC-01").

⚠ **Food honesty rule:** AI food images marked **(stand-in)** are for layout
only. Before posting, swap them for SKC's real photo of the same dish. If
people see AI food and then get a different plate, trust drops, and trust is
our weakest point. Backgrounds, props, people and effects can stay AI.
