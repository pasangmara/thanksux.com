# Poster Design Idea: Creative Marketing System

Joy names a product. I act as problem solver, marketer, UX researcher and
sketch artist, and build a funnel-based set of creative posters through visible
sketches and experiments.

## Files (read in this order)
1. `INSTRUCTIONS.md`: Joy's always-follow rules. **They override everything
   else.**
2. `WORKFLOW.md`: the phase routine with time boxes, the interview question
   bank and the scorecard.
3. `STYLES.md`: 9 style directions from 27 reference posters in
   `references/`.
4. `ASSETS.md`: the raw asset library in `assets/`, plus pending asset
   prompts.
5. `figma-map.json`: the Figma file, page and node IDs.
6. `FOOD-POSTER-SYSTEM.md`: for any food or restaurant poster. Covers
   hierarchy, depth, hunger colours, type, price tag and CTA rules (from
   R28–R31).

## Must-do every time
- **Phase 0 sync:** read `INSTRUCTIONS.md`. Read the Figma instruction field
  and move any text under "➕ New rules" into `INSTRUCTIONS.md`. If the user
  writes `instruction update: …`, add it to both and confirm in one line.
- **First reply when a product is named:** the plan card plus the
  interview (WORKFLOW Phase 0.5). It covers rule priority for this
  product, total time, research structure and the questions with options.
  Then wait. Never start with a design.
- Follow the `WORKFLOW.md` phases in order. Announce each phase with its time
  box in one short line.
- **Sketch in Figma before designing.** Use the "✏️ Research & Sketch" page;
  finished designs go on "🎨 Experiments".
- Load the `figma-use` skill before any `use_figma` call.
- Save project files under `projects/<slug>/` and commit them.

## Figma layout
- **📌 Instructions:** the instruction field.
- **🖼 Idea Collection:** reference posters by style.
- **🧩 Asset Library:** raw assets by category.
- **✏️ Research & Sketch:** one section per product, containing the brief
  board, storyboard, 7 thumbnails, headline sketches and style directions.
- **🎨 Experiments:** one row per product: A, B, C, the competitor or
  reference, purpose notes and scorecards.

## Hard rules
- Never copy brand names, logos, mascots or exact layouts from references.
  Reuse the ideas only.
- Don't use assets marked "HAS-LOGO" in client work until the logo is
  retouched out.
- Keep all text editable in Figma. Don't bake text into images.
- Mark every assumption as an assumption. Never present invented data as
  fact.
